# ADR 008 — Backend Python 3.14

- Status: accepted
- Date: 2026-09-18

## Context

`requires-python` was pinned to `>=3.13,<3.14`. Host `python3` on the
developer's machine is 3.14.4, so `make setup` failed when installing the
editable package. Keeping a parallel 3.13 install only for this repo adds
friction without a compensating product need.

## Decision

Require Python 3.14 for the backend: `requires-python = ">=3.14,<3.15"`,
Docker base `python:3.14-slim-bookworm`, and tooling targets (`ruff`, `mypy`)
aligned to 3.14.

## Consequences

- Local `make setup` uses the system 3.14 interpreter without a version override.
- Contributors and CI images must supply 3.14; 3.13 is no longer supported.
- Lock files should be regenerated on 3.14 when dependencies change (`make lock`).
