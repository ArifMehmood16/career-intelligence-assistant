Questions, bug reports, documentation fixes and noncommercial code contributions
are welcome. Read the [LICENSE](LICENSE) before using or submitting code. It allows
learning, noncommercial use, forks, modifications, sharing and collaboration with
attribution. Commercial use of the original or modified code requires explicit
prior written permission from Arif Mehmood and any other required rights holder.

## Contribution terms

By intentionally submitting a contribution for inclusion in this project, you
agree to make it available under the same [noncommercial licence](LICENSE), unless
a different written agreement is expressly accepted. You retain copyright in your
contribution. Submission does not transfer ownership or automatically grant the
maintainer or anyone else a separate commercial licence to your work.

Submit only material you have the right to contribute, and identify third-party
code, licences and notices. Keep existing attribution and distinguish your changes.
Do not submit personal CVs, private job documents, API keys or other sensitive data;
use the synthetic fixtures in `sample-data/` for examples and tests.

## Making a change

Describe the problem and proposed scope in an issue or pull request. Keep changes
focused, explain the resulting behaviour, and include relevant validation. Setup
is in [README.md](README.md) and [docs/running-locally.md](docs/running-locally.md);
engineering conventions and the workflow are in [AGENTS.md](AGENTS.md).
