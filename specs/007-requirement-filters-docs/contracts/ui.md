# Requirements UI contract

Completed Fit shows Match status and Requirement score selects, a Showing X of N
requirements live count, and Clear filters. Filtering combines both controls and
changes only card visibility. No selection matches: explain filters, retain clear.
No source requirements: retain the existing no-requirements message. Null score
is Not scored. Other analysis states render no filters. The overall fit, keyword
coverage, card evidence and retrieval trace action remain unchanged.
